Variables
-------------------------------------------------------------------------------------------------------
Primitive 	=> stores actual values 
			=> memory allocation in Stack
			=> Default value depends on datatype

Reference 	=> stores address/ reference to an object
			=> memory allocation in Heap for object and Stack for reference
			=> null, if not initialized
			=> Instance, Static, and Local
	=> Instance
		=> Declared inside class and outside method		
		=> can be shared across classes
		=> can not be shared across objects
		=> Lifetime: as long as object exists
	=> Static
		=> Declared inside class with "static" keyword
		=> can be shared across classes
		=> can be shared across objects
		=> Lifetime: as long as class is loaded	
	=> Local
		=> Declared inside method or block
		=> can not be shared across classes
		=> can not be shared across objects
		=> Lifetime: only during method or block execution
-------------------------------------------------------------------------------------------------------
Datatypes=> Java is a strictly/strongly typed programming language
-------------------------------------------------------------------------------------------------------
Primitive
	=> stores values directly in stack memory
	=> byte, short, int, long, float, double, boolean, char
Reference
	=> these refer to objects in memory(Heap), and variables hold the reference(address), not the actual value 
	=> Wrapper Classes(Byte, Short, Integer, Long, Float, Double, Boolean, Char), Strings, Arrays, Class and Object, Interface, Enum etc.,

Operators
-------------------------------------------------------------------------------------------------------
Arithmetic 	: +,-,*,/,% => for basic mathematical calculations
Logical 	: &&, ||, ! => used to check multiple conditions
Relational	: <, >, >=, <=, ==, != => used for comparsion
Assignment	: =, +=, -=, *=, /=, %= => used for assigning values
Unary		: +, -, ++, --
Shift		: <<, >>, <<<, >>>  => to shift bits
Bitwise		: &, |, ^, ~ => to work on bits
Ternary		: "?:" => shorthand if-else 
instanceof	: to check relationship or Used to check if an object is an instance of a specific class or interface
