KISS Principle (Keep It Simple, Stupid)
---------------------------------------
This principle tells that software should be designed and implemented in the simplest way possible.

Avoid unnecessary complexity, over-engineering.

Simple solutions are easy to understand and easy to maintain.

Without KISS principle
----------------------
import java.util.stream.IntStream;
class MathUtils {
  public static int factorial(int n) {
    return IntStream.rangeClosed(1, n).reduce(1, (a, b) -> a * b);
  }
}

With KISS principle
----------------------
class MathUtils {
  public static int factorial(int n) {
    int factorial = 1;
    for (int j = n; j >= 1; j--) {
      factorial = factorial * j;
    }
    return factorial;
  }
}
